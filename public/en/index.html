Laya in four steps

The installer can set up the model during your first installation. Or do it later in Settings. Already have r3? Click Оновити модель (Update model): r4 is more accurate (99.9% of words vs. 97.8%), and the old model will be removed.

  1. Open Налаштування → Як визначати мову → Laya · локально (Settings → Language detection → Laya · local).
  2. Click Завантажити й підготувати (Download and prepare).
  3. The app will download model r4 (~599 MB) from the official release and verify its SHA-256 checksum.
  4. Choose acceleration: Автоматично (Automatic), CPU or NVIDIA CUDA. If another app is using the GPU (less than 1.5 GB free), Laya automatically falls back to CPU.

Six shortcuts worth remembering

All shortcuts can be changed in “Налаштування → Гарячі клавіші” (Settings → Hotkeys). Try pressing any of them right now.

  • CtrlAltSpaceConvert selected text
  • CtrlAltBackspaceUndo the last automatic correction
  • CtrlAltPPause / resume
  • CtrlAlt1Selection → Ukrainian
  • CtrlAlt2Selection → English
  • CtrlAlt3Selection → Russian

The little things that make it feel right

  • Preserves letter case: Ghbdsn becomes Привіт, while GHBDSN — ПРИВІТ.
  • Checks each correction against Ukrainian and Russian Hunspell dictionaries to avoid suggesting a word that does not exist.
  • Also corrects words typed immediately after a click or window switch; password fields remain untouched.
  • Never loses keystrokes: if you keep typing during a replacement, your letters appear in the same order.
  • Corrects addresses too: пщщпдуюсщь becomes google.com after Space or Enter.
  • Identifies the keyboard layout itself, not the Windows language: “Русский (Украина)”, “English (Ukraine)”, Ukrainian Enhanced and Dvorak are supported too.
  • Tested in Chrome and Edge (including Gmail and Telegram Web), Notepad, Notepad++ and VS Code. For VS Code, enable "editor.accessibilitySupport": "on" — the app will prompt you.
  • Works in Scintilla-based code editors: corrections also trigger on Enter.
  • Learns from you: add an undone correction to the exceptions immediately.
  • App exclusion lists, custom rules and searchable replacements.
  • The “Перевірити оновлення” (Check for updates) button finds the latest stable release on GitHub and clearly reports a failed check.
  • Clean uninstall through “Programs and Features”.

Questions and answers

What is Switchcraft AI?

Switchcraft AI is a Windows 10 and 11 app that automatically corrects text typed in the wrong keyboard layout and switches the layout. For example, “ghbdsn” becomes “привіт”. It supports Ukrainian, English and Russian input and has a Ukrainian app interface.

How is Switchcraft AI different from Punto Switcher?

Switchcraft AI detects the language using a neural network, not just dictionaries: the offline local Laya model (mmBERT) or cloud-based TypeSafe AI. Candidates are also checked against Ukrainian and Russian Hunspell dictionaries. The app has a fully Ukrainian interface and does not require administrator rights.

Does Switchcraft AI work offline?

Yes. In Laya mode, the neural network (~599 MB) runs entirely on your computer — on the CPU or an NVIDIA GPU via CUDA. Internet access is only needed for TypeSafe AI mode and update checks.

Can Switchcraft AI see my passwords?

No. The app automatically skips password fields, password managers and protected forms. Correction history (up to 50 entries) is held only in memory during the current session and disappears when the app closes.

How do I undo an automatic correction?

Press Ctrl + Alt + Backspace to restore what you typed. You can immediately add the undone word to the exceptions so the app will not change it again.

How do I correct text I have already typed?

Select the text and press Ctrl + Alt + Space. Ctrl + Alt + 1, 2 or 3 force the selection into the Ukrainian, English or Russian keyboard layout.

Where does Switchcraft AI work?

In most Windows apps: tested with real typing in Chrome and Edge (including Gmail and Telegram Web), Notepad, Notepad++ and VS Code. Browser address-bar search queries are corrected, while correctly typed addresses such as google.com are left unchanged.

How much does Switchcraft AI cost?

You can download the app for free from GitHub: an installer (~62 MB) or a portable version. The source code is available on GitHub.
