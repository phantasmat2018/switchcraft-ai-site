Набрали ghbdsn замість привіт? Switchcraft AI помічає слово, набране не в тій розкладці, виправляє його після пробілу й сам перемикає мову. Англійська, українська, російська — без телеметрії й без запису тексту.

Завантажити для Windows Портативна версія (.zip)

Версія 1.6.2 · Windows 10/11 x64 · 62,4 МБ · без прав адміністратора

Switchcraft працює на Windows. Надішліть собі посилання й завантажте на комп’ютері.

Два способи зрозуміти, якою мовою ви пишете

Оберіть у налаштуваннях: «Налаштування → Як визначати мову». Перемкнутися можна будь-коли.

Режим Де працює Інтернет Коли обрати

Laya за чотири кроки

Інсталятор може підготувати модель одразу під час першого встановлення. Або зробіть це пізніше з налаштувань.

  1. Відкрийте Налаштування → Як визначати мову → Laya · локально.
  2. Натисніть Завантажити й підготувати.
  3. Програма завантажить модель r3 (~572 МБ) з офіційного релізу і перевірить контрольну суму SHA-256.
  4. Оберіть прискорення: Автоматично, CPU або NVIDIA CUDA.

Шість комбінацій, які варто запам’ятати

Усі змінюються в «Налаштування → Гарячі клавіші». Спробуйте натиснути будь-яку з них просто зараз.

  • CtrlAltSpaceПеретворити виділений текст
  • CtrlAltBackspaceСкасувати останнє автовиправлення
  • CtrlAltPПауза / відновити роботу
  • CtrlAlt1Виділення → українська
  • CtrlAlt2Виділення → англійська
  • CtrlAlt3Виділення → російська

Він бачить, що ви друкуєте. Тому він нічого не запам’ятовує.

Паролі
Поля паролів, менеджери паролів і захищені форми ігноруються автоматично.
Текст
Жодного журналювання й жодних набраних паролів на диску.
Історія
До 50 останніх виправлень, лише в оперативній пам’яті поточної сесії.
Телеметрія
Немає. Ні сторонньої аналітики, ні «анонімної статистики».
Ключ API
Ключ TypeSafe шифрується Windows DPAPI для поточного користувача.
Налаштування
Лежать у %LOCALAPPDATA%\Switchcraft, імпорт та експорт у JSON.

Перевірте самі

Наберіть ghbdsn в обох полях і натисніть пробіл. Так само поводиться програма: у звичайному полі вона виправить слово, у полі пароля нічого не чіпатиме.

І ще дрібниці, які роблять його своїм

  • Зберігає регістр: Ghbdsn стає Привіт, а GHBDSN — ПРИВІТ.
  • Звіряє кожне виправлення з українським і російським словниками Hunspell, щоб не підставити неіснуюче слово.
  • Не губить натискання: якщо ви друкуєте далі під час заміни, літери з’являться в тому ж порядку.
  • Виправляє й адреси: пщщпдуюсщь стає google.com після пробілу або Enter.
  • Перевірено в Chrome і Edge (зокрема Gmail і Telegram Web), Блокноті, Notepad++ і VS Code. Для VS Code увімкніть "editor.accessibilitySupport": "on" — програма підкаже.
  • Працює в редакторах коду на Scintilla: виправлення спрацьовує і на Enter.
  • Навчається: скасоване виправлення можна одразу додати до винятків.
  • Списки програм-винятків, власні правила й заміни з пошуком.
  • Кнопка «Перевірити оновлення» знаходить найновішу стабільну версію на GitHub і чесно каже, якщо перевірка не вдалася.
  • Чисте видалення через «Програми та компоненти».

Останній раз пишете ghbdsn.
